# Employee Gender Analysis

## 📊 Project Overview

This project analyzes gender representation, workforce composition, leadership representation, and salary differences using the Employees-mod dataset.

The analysis was developed using SQL for data extraction and transformation and Tableau for data visualization.

## 🎯 Objectives

- Analyze gender distribution across the workforce
- Examine gender representation across departments
- Analyze salary differences between male and female employees
- Compare gender representation in management
- Analyze workforce evolution over time

## 🛠️ Tools

- MySQL
- SQL
- Tableau
- CSV

## 📈 Dashboard

[(https://public.tableau.com/app/profile/isadora.almeida1860/viz/employees-gender-analysis/GenderEqualityAnalysis?publish=yes)]

## 🔎 Key Insights

- Women represent approximately 40% of the workforce, while men represent approximately 60%.
- Gender representation remains relatively stable throughout the observed period.
- Gender distribution is relatively consistent across departments.
- Men have higher average salaries than women across all departments analyzed.
- Women represent approximately 40% of the workforce but 33.3% of current managers.
- The workforce expanded substantially during the 1990s while the overall gender composition remained relatively stable.

## ⚠️ Analytical Note

The observed salary differences describe patterns in the dataset but do not establish their causes. Factors such as job role, seniority, tenure, and position level are not controlled for in this analysis.
